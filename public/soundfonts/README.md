# Soundfont samples

Four General MIDI guitar instruments from the **MusyngKite** soundfont, prerendered
by [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) (MIT
license). Self-hosted so playback needs no external network requests at runtime.

Loaded lazily by `src/audio/engine.ts` — one file per instrument, fetched on first
use of that instrument.
